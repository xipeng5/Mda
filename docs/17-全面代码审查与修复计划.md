## 二、跨模块接口约定（所有 Worker 严格遵守）

1. **`Debugger` ↔ `DynamicService` ↔ `tools.py`（命中序号与回调）**：
   - `Debugger` 每条命中分配单调递增整数 `seq`（从 1 起），`_hit_dict()` 保留 `"seq"` 字段。
   - `Debugger` 支持可选 `on_hit` 回调（由 `DynamicService.attach` 注册），收到 `hold=True` 命中时立即把 `tgt.state` 推至 `STATE_PAUSED` 并按 `auto_resume_ms` 启动定时器，不依赖外部轮询。
   - `DynamicService` 用 `tgt.last_synced_seq`（单调序号）代替 `len(hits)`，彻底消除 2000 条环形队列满后的游标失灵。
   - `DynamicService.resume()` 返回结构化 dict（`{"resumed": bool, ...}`），`tools.py:resume()` 直接 `_j(get_dyn().resume(serial, pid))` 不再套两层。
2. **`plan_step` ↔ `stepper.py`**：
   - `stepper.py:plan_step_out` 保持现有 R17 契约（无 `rb` 时返 `LR_STATIC_UNRESOLVED`）；`tools.py:plan_step` 支持可选 `serial`/`pid` 并在缺省时自动取 `get_dyn()` 中唯一的活跃目标 `dbg` 传给 `plan_step_out` / `plan_step_over`。
3. **`dex/api.py` ↔ `tools.py`**：
   - `dex_classes` / `dex_methods` / `dex_callers` 保持返回 `[{"error": ...}]`（兼容 `test_dex.py`）；`tools.py` 识别单元素错误列表并返回 `{"ok": False, ...}`。
4. **`tools.py` ↔ `api.py` ↔ `App.tsx`（控制台与模块卸载）**：
   - `tools._activity` 保留 `result` / `result_truncated` / `result_bytes` 广播（兼容 `test_console.py`），加线程锁保护 `_activity_log`；`RealtimeMonitor.tsx` 真正展示并复制 `detail.result`。
   - `tools.py:unload_so` / `clear_modules` 触发 `_notify_ui({"type": "modules_changed", ...})`；`App.tsx` 在同步模块时同步移除已卸载标签。
   - `api.py` 对写操作校验同源 `Origin` / `Host` / `X-MDA-Client` 头，前端 `api.ts` 统一附带 `X-MDA-Client: 1`。
